Privacy Policy

Last updated: May 20, 2026

The Highwater QBO App (the “Software”) is an internal automation tool operated by Highwater Cafe & Market (“Operator”). This Privacy Policy describes what data the Software accesses and how it handles that data.

1. Scope

The Software is used solely by the Operator to access the Operator's own QuickBooks Online (“QBO”) accounts. The Software is not offered to, marketed to, or available to any other party. It does not collect data from end users other than the Operator.

2. Data the Software Accesses

  • OAuth credentials (client ID, client secret, refresh token, realm ID) issued by Intuit, required to call the QBO API.
  • QBO data retrieved during normal operation, such as chart of accounts, journal entries, invoices, and financial reports.
  • Local input files supplied by the Operator (e.g., POS reports, payroll exports) used to construct journal entries.

3. Where Data Is Stored

  • OAuth credentials are stored locally in an environment file on the Operator's own computer. They are not transmitted to any third party other than Intuit, and only when calling the QBO API.
  • QBO data retrieved from the API is held in memory for the duration of a session and is not persisted by the Software.
  • Input files remain on the Operator's own filesystem.

4. Sharing

The Software does not share data with any third party. It communicates only with Intuit's QBO API. The Operator does not sell, rent, or disclose data accessed via the Software.

5. Security

OAuth credentials are stored in a local file readable only by the Operator's user account on the Operator's computer. The Software does not transmit data over the network except to Intuit's API endpoints, which use HTTPS.

6. Retention

The Software retains no QBO data beyond a single session. OAuth credentials are retained for as long as the Operator wishes to continue using the Software and may be revoked at any time from the Operator's QBO “Apps” settings.

7. Children

The Software is not directed to children. It accesses only the Operator's own business records.

8. Changes

This Privacy Policy may be updated from time to time. The “Last updated” date at the top of this page indicates the most recent revision.

9. Contact

Questions about this Privacy Policy may be directed to jill@highwater.cafe.
