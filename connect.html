Connecting the Highwater QBO App

Last updated: May 20, 2026

The Highwater QBO App is an internal, single-operator automation tool. It runs locally on the Operator's own computer and authenticates to QuickBooks Online using a one-time OAuth flow performed by the Operator.

To connect (or re-connect) the app to a QuickBooks Online company:

  1. Sign in to the Intuit Developer Portal at developer.intuit.com using the Operator's developer account.
  2. Open the OAuth 2.0 Playground from the developer portal.
  3. Select the “Kismet” app and the com.intuit.quickbooks.accounting scope.
  4. Click “Get authorization code” and, in the Connect to QuickBooks popup, sign in with the QBO login that has access to the desired company. Approve the connection.
  5. Click “Get tokens” to exchange the authorization code for a refresh token.
  6. Update the local environment file on the Operator's computer with the new refresh token and realm ID.

Because this is an internal-use application, no public sign-in or connection endpoint is exposed. All authorization is performed by the Operator through Intuit's own developer tools.
